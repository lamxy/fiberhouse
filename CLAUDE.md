## CodeGraph QA Docs

This project keeps durable codebase analysis notes in `.codegraph-qa-out/`.

Rules:
- For codebase questions, first check `.codegraph-qa-out/` for relevant prior Q&A and analysis notes before redoing the same investigation.
- Treat `.codegraph-qa-out/` as the local documentation library for CodeGraph-assisted analysis.
- When a new codebase analysis result should be preserved, add or update a focused Markdown file under `.codegraph-qa-out/`.
- Do not rely on graphify, graphify-out, or graphify commands for this repository.

## Commit messages

Write all new commit messages in English. Existing Chinese messages in the history stay as they are — do not rewrite them.
